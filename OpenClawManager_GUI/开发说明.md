# OpenClawManager 开发说明

## 🛠️ 开发环境说明

### **当前状态：开发版本**
- **文件夹**：`OpenClawManager_GUI`
- **用途**：日常开发、修改、测试
- **关系**：V1.0生产版本的基础

### **开发流程：**
1. 在本文件夹中修改代码
2. 测试修改后的功能
3. 确认无误后，复制到新版本文件夹
4. 在新版本文件夹中打包发布

## 📁 文件夹结构

```
OpenClawManager_GUI/
├── assets/          # 资源文件（图标、图片等）
├── build/           # PyInstaller构建临时文件（自动生成）
├── dist/            # 打包输出文件夹（包含EXE）
├── gui/             # GUI界面模块
│   ├── main_window.py      # 主窗口
│   ├── model_manager.py    # 模型管理
│   ├── channel_manager.py  # 通道管理
│   └── ...其他GUI组件
├── integration/     # 集成模块
│   ├── openclaw_integration.py  # OpenClaw集成
│   └── license_manager.py       # 授权管理
├── build.bat        # 打包脚本（双击运行）
├── main.py          # 程序主入口
├── test_pyside6.py  # PySide6测试文件
└── 开发说明.md      # 本文件
```

## 🚀 打包流程

### **打包步骤：**
1. **确保代码正确**：在开发环境中测试通过
2. **运行打包脚本**：双击`build.bat`
3. **等待打包完成**：大约1-2分钟
4. **检查输出**：在`dist`文件夹中生成EXE
5. **测试EXE**：在不同环境下测试运行

### **build.bat内容：**
```batch
@echo off
pyinstaller --onefile --windowed --icon=assets/icon.ico --name "码泓 mahong-OpenClaw管理器" main.py
pause
```

### **打包注意事项：**
1. 打包前关闭所有Python相关进程
2. 确保所有依赖包已安装
3. 测试EXE在干净环境中的运行
4. 检查杀毒软件是否误报

## 🔄 版本发布流程

### **从开发版本创建新生产版本：**

#### **步骤1：创建新版本文件夹**
```powershell
# 复制当前开发版本到新版本
Copy-Item OpenClawManager_GUI OpenClawManager_Pro_V2.0 -Recurse

# 或从V1.0升级
Copy-Item OpenClawManager_Pro_V1.0 OpenClawManager_Pro_V2.0 -Recurse
```

#### **步骤2：在新版本中修改**
1. 在`OpenClawManager_Pro_V2.0`文件夹中修改代码
2. 测试新功能
3. 修复发现的问题

#### **步骤3：打包新版本**
1. 运行`build.bat`重新打包
2. 测试新EXE
3. 更新版本说明

#### **步骤4：发布准备**
1. 更新销售材料中的版本信息
2. 准备更新说明
3. 通知用户

## ⚙️ 技术栈说明

### **核心框架：**
- **GUI框架**：PySide6（Qt for Python）
- **打包工具**：PyInstaller
- **代码保护**：PyArmor（可选）
- **加密算法**：AES-256（本地数据加密）

### **开发环境：**
- **Python版本**：3.10+
- **IDE推荐**：VS Code、PyCharm

## 🐛 常见问题处理

### **打包问题：**
1. **EXE文件过大**：使用`--onefile`参数，排除不必要的包
2. **启动报错**：检查依赖包是否完整，使用`--hidden-import`参数
3. **图标不显示**：确保图标文件路径正确，使用绝对路径

### **运行问题：**
1. **杀毒软件误报**：申请数字签名，或引导用户添加信任
2. **兼容性问题**：测试不同Windows版本，使用兼容模式
3. **权限问题**：以管理员身份运行，或修改文件权限

### **开发问题：**
1. **PySide6导入错误**：重新安装PySide6，检查Python版本
2. **模块找不到**：检查PYTHONPATH，使用相对导入
3. **界面布局错乱**：使用Qt Designer设计，保持布局一致

## 📝 代码规范

### **命名规范：**
- **文件命名**：小写字母，下划线分隔，如`main_window.py`
- **类命名**：大驼峰，如`MainWindow`
- **函数命名**：小写字母，下划线分隔，如`load_config`
- **变量命名**：小写字母，下划线分隔，如`user_name`

### **代码结构：**
1. **导入模块**：标准库 → 第三方库 → 本地模块
2. **类定义**：每个类单独文件，职责单一
3. **函数定义**：功能明确，参数合理，有文档字符串
4. **异常处理**：合理使用try-except，记录错误日志

### **注释规范：**
1. **文件头注释**：说明文件用途、作者、日期
2. **函数注释**：说明功能、参数、返回值
3. **复杂逻辑注释**：解释算法和业务逻辑
4. **TODO注释**：标记待完成的功能
