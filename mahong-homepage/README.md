# 码泓科技官网

这是码泓科技的官方网站代码。

## 项目结构

```
mahong-homepage/
├── index.html          # 官网首页
├── README.md           # 项目说明
└── images/             # 图片资源目录
    ├── logo.svg        # 公司Logo
    ├── xdd-icon.svg    # 小图标
    └── advantage-*.png # 优势展示图片
```

## 技术栈

- HTML5
- CSS3 (纯CSS，无框架)
- JavaScript (原生JS，无框架)
- 响应式设计

## 功能特点

1. **响应式设计**：适配手机、平板、电脑等各种设备
2. **现代UI**：采用现代化设计风格，简洁美观
3. **性能优化**：纯静态页面，加载速度快
4. **SEO友好**：语义化HTML结构，利于搜索引擎收录
5. **交互体验**：平滑滚动、悬停效果等交互设计

## 部署说明

### 本地开发
1. 直接使用浏览器打开 `index.html` 即可预览

### 服务器部署
1. 将整个目录上传到Web服务器（如Nginx、Apache）
2. 配置域名指向该目录
3. 确保图片资源路径正确

### GitHub Pages部署
1. 将代码推送到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择主分支作为发布源

## 内容更新

### 修改文本内容
直接编辑 `index.html` 文件中的相应部分

### 更换图片
1. 将新图片放入 `images/` 目录
2. 在 `index.html` 中更新图片路径

### 添加新页面
1. 创建新的HTML文件
2. 在导航栏中添加链接
3. 保持一致的样式设计

## 注意事项

1. 所有图片资源应放在 `images/` 目录下
2. 保持CSS样式的一致性
3. 定期备份代码
4. 测试不同浏览器的兼容性
